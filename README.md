# User Management System

## Project Overview
The User Management System is a Python-based application developed using Streamlit and MySQL to perform real-time CRUD operations with persistent database storage. This project simulates the core authentication functionality commonly found in modern web applications and focuses on backend logic, database integration, and interactive application development.

The system allows users to register, log in, update account credentials, and delete their accounts while maintaining session state for a seamless user experience.

## Features
- User registration with input validation (username length, password strength, and confirmation)
- Secure login using credentials stored in MySQL
- Update username and password functionality
- Delete user account with database synchronization
- Session-based authentication and logout handling
- Interactive and user-friendly Streamlit interface

## Technologies Used
- Python for application logic and backend processing
- Streamlit for building the interactive user interface
- MySQL for database management and persistent storage
- SQL for performing CRUD operations
- Regular Expressions (Regex) for password validation

## Learning Outcomes
Through this project, I gained hands-on experience in implementing CRUD operations on a relational database, integrating Python applications with MySQL, managing user sessions, and building form-based multi-page applications using Streamlit. The project strengthened my skills in Python programming, database management, input validation, and interactive application development.
